PMDM · Cheatsheet de referencia rápida

1 val vs var

val no se puede reasignar. var sí se puede reasignar.

val nombre: String = "Ana"     // no cambia
var intentos: Int = 0           // puede cambiar
intentos = intentos + 1           // OK
// nombre = "Luis"              // ERROR: val no se reasigna

2 Nombrar variables

Empieza por letra o _. Sin espacios. Distingue mayúsculas: edad y Edad son distintas.

Convención: nombreUsuario para variables y funciones (camelCase), NombreUsuario para clases (PascalCase).

3 Plantillas de texto

$variable inserta el valor. ${expresión} inserta el resultado de una expresión.

val nombre = "Ana"
val edad = 22
val saludo = "Hola, $nombre. Tienes ${edad + 1} años."

Ojo: 12 es Int, 12.0 es Double. "12" entre comillas es String.

? Tipos nullable

Añadir ? al tipo indica que puede ser null (ausencia de valor).

val numero: Int? = "abc".toIntOrNull()  // null (no es número)
val otro: Double? = "3.5".toDoubleOrNull() // 3.5
Regla: No puedes usar <, > etc. con un Int? directamente. Primero comprueba que no es null.

€ Dos decimales

Para mostrar importes con 2 decimales y coma española:

import java.util.Locale

val total = 12.5
val texto = String.format(Locale("es", "ES"), "%.2f €", total)
// texto = "12,50 €"

// Dentro de una plantilla:
tvResultado.text = "Total: ${String.format(Locale("es", "ES"), "%.2f", total)} €"
Truco: crea una función para no repetirlo:
fun formato(valor: Double) = String.format(Locale("es", "ES"), "%.2f €", valor)

÷ División entera: redondear hacia arriba

Entre dos Int, / corta los decimales. Truco para contar tramos empezados (cada hora iniciada cuenta entera):

val minutos = 61
val horas = (minutos + 59) / 60   // 2 (Int / Int)

// 60 → 1 · 61 → 2 · 120 → 2 · 121 → 3

% Porcentajes

val recargo   = subtotal * 0.20       // el 20 % de subtotal
val conRecargo = subtotal * 1.20     // subtotal + 20 %
val descuento = total * 0.10          // el 10 % de total
val conDesc   = total * 0.90          // total - 10 %
val conIva    = base * 1.21           // base + 21 % IVA
El orden importa: si dice "aplica X y DESPUÉS Y", calcula X primero y usa ese resultado para Y.

.. Rangos con in / !in

a..b incluye ambos extremos. Sirve para validar rápido.

if (valor in 1..10) { // entre 1 y 10, ambos incluidos }
if (valor !in 1..10) { // fuera del rango }

// Con Double también vale:
if (numero !in 0.0..10.0) { tvResultado.text = "Fuera de rango" }

?: if / else if / else

Ejecuta un bloque según una condición Boolean.

if (edadNum == null || edadNum < 0 || edadNum > 120) {
    resultado.text = "Edad no válida"
} else if (edadNum < 18) {
    resultado.text = "Menor de edad"
} else if (edadNum > 65) {
    resultado.text = "Mayor de 65"
} else {
    resultado.text = "Acceso permitido"
}
Siempre: comprueba null primero con ||. Si es null, Kotlin no evalúa el resto.

W when

Elige entre varios casos. Se detiene en el primero que coincide.

val calificacion = when (notaNum) {
    in 0..4   -> "Suspenso"
    5, 6      -> "Aprobado"
    7, 8      -> "Notable"
    9, 10     -> "Sobresaliente"
    else      -> "No válida"
}

También sirve para elegir operación:

val valor = when (operacion) {
    "+" -> a + b
    "-" -> a - b
    "*" -> a * b
    "/" -> a / b
    else -> return
}

W when SIN argumento (con condiciones)

Para usar <, >, &&, ||... quita el paréntesis del when. Cada rama es una condición.

val estado = when {
    valor < 0.0  -> "Negativo"
    valor == 0.0 -> "Cero"
    else         -> "Positivo"
}

// Condiciones ordenadas: basta con el límite superior
val categoria = when {
    numero < 5 -> "Bajo"
    numero < 7 -> "Medio"
    numero < 9 -> "Alto"
    else       -> "Máximo"
}
UsaCuando
when (variable)Comparas con valores concretos o rangos: 5, 6 ->, in 1..3 ->, "+" ->
when { }Necesitas condiciones: <, >, &&, ||
Si asignas el when a un val, necesita else obligatoriamente.

= if como expresión

if también puede devolver un valor (como un operador ternario).

val mensaje = if (numero >= 5) "Superado" else "No superado"

val extra = if (cbOpcion.isChecked) 4.0 else 0.0

tvResultado.text = if (texto.isEmpty()) {
    "Campo obligatorio"
} else {
    "Hola, $texto"
}

fn Anatomía de una función

//  nombre         parámetro       tipo retorno
//    ↓               ↓               ↓
fun celsiusAFahrenheit(celsius: Double): Double {
    val resultado = ((celsius * 9) / 5) + 32
    return resultado   // ← lo que devuelve
}
PiezaQué es
funPalabra clave para declarar función
celsius: DoubleParámetro: dato que recibe (nombre: Tipo)
: Double tras ()Tipo del valor que devuelve
returnDevuelve el resultado y sale de la función
privateSolo accesible dentro de la misma clase

→ Llamar a una función

// Se llama pasando un argumento (el valor real)
val f = celsiusAFahrenheit(25.0)  // f = 77.0

// Dentro de un string template
resultado.text = "${celsiusAFahrenheit(100.0)} ºF"
Parámetro = la variable en la definición. Argumento = el valor que pasas al llamar.

∅ Función sin retorno

Si solo realiza una acción (mostrar un Log, por ejemplo), no necesita tipo de retorno ni return.

private fun mostrarMensaje(texto: String) {
    Log.d("PMDM", texto)
}

! return sin valor

Dentro de un listener o función local, return sin valor detiene la ejecución (como un "para aquí").

fun calcular(op: String) {
    val a = entrada1.text.toString().toDoubleOrNull()
    if (a == null) {
        salida.text = "Número no válido"
        return  // para aquí, no sigue calculando
    }
}

@ return dentro de setOnClickListener

Dentro del { } de un listener, un return solo NO compila. Hay que poner la etiqueta:

btnCalcular.setOnClickListener {
    val numero = etCampo1.text.toString().toIntOrNull()
    if (numero == null) {
        tvResultado.text = "Dato no válido"
        return@setOnClickListener   // sale del listener
    }
    // aquí numero ya no es null
}
Alternativa: usar if / else if / else y meter el cálculo en el else final, sin return.

? Función que puede devolver null

Pon ? en el tipo de retorno. Útil cuando la operación puede no tener resultado.

private fun dividir(a: Double, b: Double): Double? {
    if (b == 0.0) return null
    return a / b
}

val resultado = dividir(10.0, 0.0)
tvResultado.text = if (resultado == null) "No se puede dividir entre cero"
                   else "Resultado: $resultado"

P Funciones de cálculo "puras"

Reciben números y devuelven un resultado. No tocan los EditText ni los TextView: eso se hace en el listener.

// ✅ Recibe datos, devuelve resultado
fun calcularTotal(base: Double, extra: Double, conRecargo: Boolean): Double {
    val subtotal = base + extra
    return if (conRecargo) subtotal * 1.20 else subtotal
}

// En el listener: leer → validar → llamar → mostrar
btnCalcular.setOnClickListener {
    val base = etCampo1.text.toString().toDoubleOrNull()
    val extra = etCampo2.text.toString().toDoubleOrNull()
    if (base == null || extra == null || base < 0 || extra < 0) {
        tvResultado.text = "Datos no válidos"
    } else {
        val total = calcularTotal(base, extra, cbOpcion.isChecked)
        tvResultado.text = "Total: $total"
    }
}

2 Tarifa por tramos (solo el exceso)

Cuando los primeros X van a un precio y el resto a otro, el precio caro solo se aplica a lo que sobra:

fun costeTramos(cantidad: Double): Double {
    return if (cantidad <= 100) {
        cantidad * 0.12
    } else {
        100 * 0.12 + (cantidad - 100) * 0.18
    }
}

Declara el var en onCreate FUERA del listener. Si lo pones dentro, vuelve a empezar en cada clic.

var contador = 0             // fuera: recuerda el valor
var disponibles = 20         // fuera: recuerda el valor

btnAccion.setOnClickListener {

◉ RadioGroup en Kotlin

checkedRadioButtonId devuelve el id del marcado, o -1 si no hay ninguno.

import android.widget.RadioGroup

val rgOpciones = findViewById<RadioGroup>(R.id.rgOpciones)

btnCalcular.setOnClickListener {
    val seleccion = rgOpciones.checkedRadioButtonId

    if (seleccion == -1) {
        tvResultado.text = "Elige una opción"
    } else {
        val precio = when (seleccion) {
            R.id.rbOpcion1 -> 1.80
            R.id.rbOpcion2 -> 1.10
            else -> 0.0
        }
        val nombre = if (seleccion == R.id.rbOpcion1) "Opción 1" else "Opción 2"
        tvResultado.text = "$nombre: $precio €"
    }
}
Quitar selección: rgOpciones.clearCheck(). No necesitas hacer findViewById de cada RadioButton, basta con el grupo.

3 Aplicar un estilo

Se pone style="@style/Nombre" (sin android: delante). Cada vista sigue llevando SU id y lo que la hace única (hint, inputType, text).

<EditText
    android:id="@+id/etCampo1"
    style="@style/CampoFormulario"
    android:hint="Primer dato"
    android:inputType="number" />

<Button
    android:id="@+id/btnCalcular"
    style="@style/BotonPrincipal"
    android:text="Calcular" />

<TextView
    android:id="@+id/tvResultado"
    style="@style/TextoResultado"
    android:text="Introduce los datos" />
Si el estilo ya pone width y height, no hace falta repetirlos en la vista.

4 Fondo redondeado: res/drawable/fondo_panel.xml

Clic derecho en drawable → New → Drawable Resource File → nombre fondo_panel, raíz shape.

<shape xmlns:android="http://schemas.android.com/apk/res/android"
    android:shape="rectangle">
    <solid android:color="@color/colorFondo" />       <!-- relleno -->
    <corners android:radius="16dp" />              <!-- esquinas -->
    <stroke android:width="1dp" android:color="#CDDDE3" /> <!-- borde -->
</shape>

Se aplica con android:background="@drawable/fondo_panel" en un TextView o LinearLayout. Añade android:padding para que el texto no toque el borde.

B Qué es

Permite usar las vistas del XML directamente desde Kotlin, sin findViewById. Android crea una variable por cada vista que tenga android:id.

1 Activarlo en Gradle

En app/build.gradle.kts (el de Module :app), dentro de android { }:

android {
    // ... lo que ya hay ...

    buildFeatures {
        viewBinding = true
    }
}

Después pulsa Sync Now (barra amarilla de arriba) y espera a que termine.

2 El XML genera su clase Binding

El nombre se saca del archivo del layout: pasa a PascalCase y se le añade Binding.

LayoutClase que se genera
activity_main.xmlActivityMainBinding
activity_ticket.xmlActivityTicketBinding

3 Preparar la Activity

import com.example.tupaquete.databinding.ActivityMainBinding

class MainActivity : AppCompatActivity() {
    private lateinit var binding: ActivityMainBinding

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        binding = ActivityMainBinding.inflate(layoutInflater)
        setContentView(binding.root)   // sustituye a setContentView(R.layout.activity_main)

        // aquí tu código
    }
}

setContentView(binding.root)Muestra esa pantalla

⇄ findViewById vs View Binding

// ── Con findViewById ──
setContentView(R.layout.activity_main)
val etCampo1 = findViewById<EditText>(R.id.etCampo1)
val tvResultado = findViewById<TextView>(R.id.tvResultado)
tvResultado.text = etCampo1.text.toString()

// ── Con View Binding ──
binding = ActivityMainBinding.inflate(layoutInflater)
setContentView(binding.root)
binding.tvResultado.text = binding.etCampo1.text.toString()

Declarar cada vistaSí, una línea por vistaNo hace falta
Tipo equivocado (<EditText> en un TextView)Compila y la app se cierraImposible: el tipo lo pone Android
Id que no existeFalla al ejecutarSale en rojo al escribir
Imports de vistas (EditText, Button...)NecesariosNo hacen falta
No mezcles: usa una forma u otra en el mismo proyecto. Todo lo demás (validar, when, funciones...) es igual.

⚠ Si algo sale en rojo

  • ¿Está viewBinding = true en el build.gradle.kts de app y has hecho Sync Now?
  • ¿Hay algún error en el XML? Si el XML no compila, no se genera el Binding.
  • ¿El nombre de la clase coincide con el del layout? activity_main → ActivityMainBinding.
  • ¿El import tiene tu paquete y termina en .databinding.ActivityMainBinding?
  • ¿La vista tiene android:id? Sin id no aparece en binding.
  • Si sigue fallando: Build → Rebuild Project.

⚠ import android.R

Si importas android.R, sobreescribe la R de tu proyecto y nada de tu XML se encuentra.

Solución: Borra la línea import android.R.

⚠ Comparar un nullable

No puedes hacer edadNum < 18 si edadNum es Int?. Comprueba null primero.

// ❌ MAL
if (edadNum < 18) { ... }

// ✅ BIEN
if (edadNum == null || edadNum < 18) { ... }

⚠ .toString() en EditText

miEditText.toString() devuelve el objeto, no el texto que escribió el usuario.

// ❌ MAL
val texto = miEditText.toString()

// ✅ BIEN
val texto = miEditText.text.toString()

⚠ Leer el texto fuera del listener

Si lees .text.toString() fuera del listener, lees el valor al crear la pantalla (vacío).

// ❌ MAL — lee vacío porque el usuario aún no ha escrito
var num = temperatura.text.toString().toDoubleOrNull()
boton.setOnClickListener { ... }

// ✅ BIEN — lee dentro del listener, cuando el usuario ya escribió
boton.setOnClickListener {
    val num = temperatura.text.toString().toDoubleOrNull()
    ...
}

⚠ return 0.0 en vez del resultado

Si calculas el resultado pero haces return 0.0, siempre devuelve cero.

// ❌ MAL
fun calcular(x: Double): Double {
    val resultado = x * 2
    return 0.0  // ignora el cálculo
}

// ✅ BIEN
fun calcular(x: Double): Double {
    val resultado = x * 2
    return resultado
}

⚠ Doble declaración XML

Solo una línea <?xml ...?> por archivo. Si hay dos, da error.

⚠ Package no coincide

La línea package en MainActivity.kt debe coincidir con la carpeta del archivo. Si copias de otro proyecto, cámbialo.

⚠ Comparar Double con Int usando ==

== no deja comparar Double con Int. Con < y > sí se puede mezclar.

// ❌ MAL (valor es Double)
if (valor == 0) { ... }
valor.equals(0)          // compila pero SIEMPRE da false

// ✅ BIEN
if (valor == 0.0) { ... }
if (valor < 0) { ... }    // esto sí funciona

⚠ Condiciones en when (variable)

Con argumento, cada rama se compara por igualdad. Para condiciones, quita el argumento.

// ❌ MAL
val estado = when (valor) {
    valor < 0 -> "Negativo"
}

// ✅ BIEN
val estado = when {
    valor < 0 -> "Negativo"
    else -> "No negativo"
}

⚠ Falta el else en un when asignado

Si haces val x = when { ... } sin else, da error: 'when' expression must be exhaustive.

⚠ return solo dentro de un listener

// ❌ MAL: 'return' is not allowed here
btnCalcular.setOnClickListener { if (numero == null) return }

// ✅ BIEN
btnCalcular.setOnClickListener { if (numero == null) return@setOnClickListener }

Dentro de una fun local (como calcular()) el return normal sí vale.

⚠ && y || mezclados sin paréntesis

// ❌ MAL: se lee como (op == "/" && a == 0.0) || b == 0.0
if (op == "/" && a == 0.0 || b == 0.0)

// ✅ BIEN: el divisor es el segundo número
if (op == "/" && b == 0.0)

⚠ Contador que no avanza

Si el var contador = 0 está DENTRO del listener, se reinicia en cada clic. Ponlo fuera, en onCreate.

⚠ Restar antes de validar

Valida TODO primero (nulls, rangos, que haya suficiente...). Solo cuando todo es correcto, calcula, resta del contador y muestra.

⚠ Usar un dato inválido de RadioGroup

Comprueba checkedRadioButtonId == -1 antes de calcular, o calcularás con una opción que no existe.

⚠ ScrollView con varios hijos

Error ScrollView can host only one direct child. Mete todas las vistas dentro de un único LinearLayout.

⚠ Falta el import de una vista nueva

Si CheckBox, RadioGroup o Color salen en rojo, falta el import. En Android Studio: cursor encima y Alt + Enter.

⚠ Estilo no encontrado

Si @style/Nombre da error, revisa que styles.xml esté en res/values/, dentro de <resources>, y que el nombre coincida exactamente (mayúsculas incluidas).
